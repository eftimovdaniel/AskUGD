# OCR артефакти

- `cache/` — кеширан текст по отпечаток на страница (не се комитира)
- `za_pregled/` — документи со можни лични имиња; **не влегуваат во Qdrant** до рачен преглед
- `ocr_failed.txt` — страници со ниска доверба

По преглед: избриши ги имињата/индексите од `.txt`, потоа пушти посебен ingest само за тој извор (или премести го во `data/pdfs` како исчистен документ).
